# 붙여넣기 배포 (사용자가 "Cloudflare에 올리지 말고 파일만 줘"라고 했을 때)

**한 페이지 = Worker 하나.** 그 페이지의 위젯은 전부 `worker.js` 한 파일에 들어 있고, 주소 뒤 이름(`/memo`, `/budget`)으로 나뉜다.
처음 한 번은 Cloudflare 무료 계정(dash.cloudflare.com/sign-up)이 필요하다.
위젯을 고치거나 늘릴 때는 1번(Worker 만들기)·3번(비밀값)을 건너뛰고 **2번만** 다시 하면 된다.

## 1. Worker 만들기 (이 페이지 처음 한 번)
1. Cloudflare 로그인 → 왼쪽 **Workers 및 Pages** → **애플리케이션 생성**
2. **Hello World로 시작하십시오!** 선택
3. 이름 입력(예: `<페이지 영어 이름>-widgets`) → **배포**. 이 이름이 주소가 된다.

## 2. 코드 붙여넣기
1. 오른쪽 위 **코드 편집**
2. 왼쪽 코드를 전부 지우고(윈도우 Ctrl+A / 맥 Cmd+A → Delete) `worker.js` 내용을 전부 붙여넣기 → 오른쪽 위 **배포**
3. 아래 상태줄이 `⊗ 0` 이면 오류 없음.
4. **화면 확인(확인 ②)**: 개요 탭의 주소 끝에 `/?demo=1` 을 붙여 열면 모든 위젯이 가짜 데이터로 한 화면에 뜬다. 비밀값 없이도 보인다. 노션 칸에 넣은 크기가 궁금하면 `/<이름>?demo=1` 주소로 임시 임베드해서 끌어 본다. 고칠 곳이 있으면 새 worker.js 를 받아 2번을 다시 한다.

## 3. 비밀값 넣기 (노션 데이터를 쓰는 위젯이 있을 때, 처음 한 번)
1. **노션 토큰**: notion.so/profile/integrations → Connections → **+ New connection** → 이름 → **API token** → Create → 복사(`ntn_` 로 시작). 이미 만든 연결이 있으면 그 토큰을 써도 된다.
2. Worker **설정** 탭 → **변수 추가** → 아래 2개를 각각 **비밀** 체크 → **변수 추가 및 배포**
   - `NOTION_TOKEN` = 노션 토큰
   - `WIDGET_SECRET` = 클로드가 클립보드에 복사해 준 위젯 비밀번호 (값 칸에서 Cmd+V / Ctrl+V. 직접 정한다면 **영문+숫자만** 20자 이상)
3. "암호화된 값"으로 보이면 끝. 이 Worker의 모든 위젯이 같이 쓴다.
4. **노션 DB에 연결 추가**: 위젯이 쓰는 **DB마다** 오른쪽 위 `···` → **연결** → **연결 추가하기** → 1에서 만든 연결. 빼먹으면 "shared with your integration" 오류. 새 위젯이 새 DB를 쓰면 그 DB에도 추가한다.

## 4. 노션에 붙이기
1. 위젯 주소: 개요 탭 맨 위 주소 + `/<위젯 이름>?k=<WIDGET_SECRET>` (데이터 없는 위젯은 `?k=` 없이). Worker 주소만 열면 위젯별 주소 목록이 나온다.
2. 노션 놓을 자리 빈 줄에 `/embed` → **임베드** → 주소 붙여넣기 → **링크 임베드**.
3. 크기는 위젯 가장자리를 끌어서 조절한다.

## 5. 안 될 때: 점검 화면
위젯 주소 끝에 `&check=1` 을 붙여 브라우저로 연다(예: `…workers.dev/budget?k=<WIDGET_SECRET>&check=1`). `…workers.dev/?k=<WIDGET_SECRET>&check=1` 은 모든 위젯을 한 번에 본다.
비밀값 → 키 → 노션 토큰 → 위젯별 DB 연결 → 속성 이름 → 목록 읽기를 차례로 ✅/❌ 로 보여주고, ❌ 옆에 고치는 법을 적어 준다.
고치는 법이 어려우면 이 화면을 캡처해서 클로드 코드에 보여준다. 토큰·비밀번호 값은 이 화면에 나오지 않는다.

## 주의
- `k=` 가 들어간 주소는 비밀번호와 같고, 같은 Worker의 다른 위젯도 열 수 있다. 페이지를 공개 공유하거나 템플릿으로 나눠줄 땐 그 임베드를 빼고 공유한다.
- 토큰은 채팅창·노션 페이지·스크린샷에 붙여넣지 않는다. Cloudflare **비밀** 칸에만.
- 고친 뒤 다른 위젯까지 멈추면 `worker.이전.js` 를 2번처럼 다시 붙여넣어 되돌린다.
