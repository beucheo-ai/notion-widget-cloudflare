# 노션에 위젯 바로 붙이기 (사용자가 "바로 붙여줘"를 골랐을 때)

노션 연결(Notion MCP)로 임베드 블록을 넣는다. 위젯 주소마다 블록 하나.

## 자리 고르기
1. 페이지를 fetch 해서 위에서부터 짧은 목록을 만든다. 예:
   ```
   ① 페이지 맨 위
   ② '오늘 할 일' 박스 아래
   ③ 오른쪽 칸 맨 위
   ④ 페이지 맨 아래
   ```
2. 사용자가 고르면 그 자리에 넣는다. 위젯이 여러 개면 위젯마다 자리를 묻거나 "한 자리에 차례로"인지 묻는다.

## 넣는 법 (update-page)
- 넣을 블록: `<embed src="<위젯 주소>"></embed>`
- **맨 위/맨 아래**: `insert_content` 의 `position` start / end.
- **특정 블록 아래·위**: `update_content` 로 그 블록의 **짧고 유일한 한 줄**을 찾아 바꾼다.
  - 아래에 넣기: `old_str` = 그 줄, `new_str` = 그 줄 + 줄바꿈 + 임베드
  - 위에 넣기(칸 맨 위 등): `old_str` = 그 칸 첫 블록의 한 줄, `new_str` = 임베드 + 줄바꿈 + 그 줄 (칸 안이면 같은 탭 들여쓰기)
- **콜아웃(박스)·토글을 통째로 다시 쓰지 않는다**: 직접 올린 아이콘이 지워질 수 있다. 박스 "아래"에 넣을 때는 박스 다음 블록의 줄 앞에 넣는다. 박스 다음 블록이 없거나 애매하면 사용자에게 "박스 바로 아래 빈 줄"을 만들어 달라고 하거나 다른 자리를 고르게 한다.
- `old_str` 에 위젯 주소의 `k=` 값이 들어가는 기존 임베드 줄은 쓰지 않는다.

## 넣은 뒤
- 페이지를 다시 fetch 해서 임베드가 고른 자리에 있는지 확인한다(주소의 `k=` 값은 말하지 않는다).
- "높이는 노션이 정해 줄 수 없어서, 위젯 아래 가장자리를 끌어 맞춰 주세요. 좁은 칸은 300px 안팎이 보기 좋아요."
- 실패하면(못 찾음·권한 없음) 주소를 직접 붙이는 방법으로 바꾼다.
